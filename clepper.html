Desktop video tool

Long videos → vertical clips with subtitles

clepper is a local desktop application that turns long recordings into short vertical clips for TikTok, Reels and Shorts. It transcribes speech, finds engaging moments, burns in styled subtitles, and can upload finished clips to TikTok with the creator’s permission.

Terms of Service Privacy Policy

What it does

Local speech recognition

Whisper runs on the user’s computer, producing word-level timestamps for accurate subtitles.

Highlight detection

Heuristics and optional LLM selection find self-contained, engaging moments in long videos.

Vertical rendering

Creates 9:16 MP4 clips with a blurred background, center crop or original framing.

Styled subtitles

Burns in captions with active-word highlighting, outlines and TikTok-friendly styling.

TikTok integration

With explicit authorization, uploads finished clips through TikTok’s official Content Posting API.

Local-first privacy

Videos and transcripts stay on the user’s machine unless the user chooses to upload or use an external service.

How it works

The user selects a video file or provides a link, chooses a processing profile, and reviews the selected moments. clepper renders the clips locally. If the user connects a TikTok account, the selected clip, caption and privacy settings are sent to TikTok only when the user starts an upload.
