Files for TikTok developer app review
=====================================

Upload these three files to the GitHub Pages repository that serves
https://milovv13.github.io/rezume/

  clepper.html   -> https://milovv13.github.io/rezume/clepper.html
  terms.html     -> https://milovv13.github.io/rezume/terms.html
  privacy.html   -> https://milovv13.github.io/rezume/privacy.html

Before uploading, replace the placeholder:

  your-email@example.com

with a real contact email (in all three files). You can use a GitHub
issues URL as a secondary contact; it is already included.

Where to upload
---------------
Put the files in the same folder as the published index.html:
- if GitHub Pages serves the repository root, upload to the root;
- if GitHub Pages serves /docs, upload to docs/;
- if GitHub Pages serves the gh-pages branch, upload to that branch.

After uploading
---------------
1. Wait 1-3 minutes for GitHub Pages to rebuild.
2. Check that these URLs open as pages (not 404):
   https://milovv13.github.io/rezume/clepper.html
   https://milovv13.github.io/rezume/terms.html
   https://milovv13.github.io/rezume/privacy.html
3. Paste the Terms and Privacy URLs into the TikTok app form.
4. Use the clepper.html URL as the app website, if the form asks for one.

TikTok app description (English)
--------------------------------
clepper is a desktop tool for creators that turns long videos into
vertical short clips. It runs speech recognition locally, finds engaging
moments, burns in styled subtitles, and exports 9:16 MP4 files. With the
user's permission, clepper can upload finished clips to TikTok through
TikTok's official Content Posting API. Video processing happens on the
user's computer; clips are sent to TikTok only when the user starts an
upload.
